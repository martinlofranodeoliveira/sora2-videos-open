# Contribution boundaries

Work only from this public repository and appropriately licensed public sources.
Do not read the former private application's configuration, data or Git history.
Add useful complete features with regression tests and meaningful commits.
Run `npm test` and `npm run demo`; do not call paid providers during tests.
Keep provider credentials inside adapters, never in job specs, errors or records.
Document whether a test uses a simulated provider or actual media processing.
Do not present the retired OpenAI Sora 2 API as available.
